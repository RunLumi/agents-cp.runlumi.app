# Work Packet Handoff — P01-QA-01

## What changed

Added the workspace lockfile, explicit pnpm dependency-build allowlist, GitHub Actions checks workflow, and a reproducible local smoke command that applies D1 migrations and exercises the local web-to-Worker-to-D1/outbox/Queue path.

## Contracts consumed

- Contract Gate commit: `7835fd9` (`p01-cg-v1`)
- APIs: health/meta/error/idempotency/outbox-status contracts
- Permissions: no real principals or tenant product routes; synthetic scope rows only
- Events: frozen `EventEnvelope`, local fixture event
- Schema/policy versions: migration `0001_p01_foundation.sql`

## Contracts produced

- `pnpm-lock.yaml` pins the full declared workspace graph
- `pnpm smoke:local` checks local migration, principal/org scope separation, stale-claim batch rollback, expired-key reclaim without changing an active claim, request/correlation propagation into D1, one outbox event after duplicate replay, different-body conflict, queue delivery, and production-config omission of dev routes
- `.github/workflows/checks.yml` runs the repository quality commands and Worker/web dry-run builds

## Database/migration impact

- Migration: runs Wrangler local migrations before the smoke flow
- Indexes/constraints: smoke asserts D1 idempotency scope uniqueness
- Rollback/forward strategy: test DB is local and isolated; schema corrections append forward migrations

## Runtime/deployment impact

- New bindings/env/secrets: local/prod Wrangler environments have explicitly distinct named D1 and Queue resources; no account IDs or credentials are checked in
- Worker compatibility: CI installs Worker WASM target and worker-build; dry run is production-config only and never deploys
- Client-version assumptions: CI requires the exact lockfile and pinned pnpm

## Known limitations

- Hosted GitHub Actions and any real Cloudflare resource/deployment were not run when this handoff was prepared. Hosted checks must pass on the implementation PR before phase exit.
- Production backup/restore verification and RPO/RTO evidence remain out of P01's local substrate proof and must be completed in hardening/operations work.

## Downstream agent notes

Run `pnpm smoke:local` before treating a contract change as integrated. It uses no remote D1 or Queue resource and writes only fixture data to Wrangler local state.

## Do not assume

- A local Worker dry run proves a production deployment or remote D1 migration.
- Queue messages are exactly-once.
- The smoke fixture consumer handles product-specific events.
