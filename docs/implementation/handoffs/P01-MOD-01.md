# Work Packet Handoff — P01-MOD-01

## What changed

Added Worker-independent core value types for opaque resource IDs, request/correlation context, UTC timestamps, API errors, pagination, idempotency, and versioned event envelopes. Debug formatting redacts actor identifiers, payloads, stored response bodies, and idempotency material.

## Contracts consumed

- Contract Gate commit: `7835fd9` (`p01-cg-v1`)
- APIs: `ApiError`, `RequestContext`, `Page<T>`
- Permissions: none; P01 defines placeholders only
- Events: `EventEnvelope`, versioned `EventType`
- Schema/policy versions: no database types in core

## Contracts produced

- Typed IDs: `ResourceId`, `RequestId`, `EventId`, `OrganizationId`, `DeviceId`, `SessionId`, `ActorId`, `CorrelationId`
- `Timestamp`, `ActorContext`, `RequestContext`
- `ApiError`, `ApiErrorCode`, `CoreError`
- `Cursor`, `Page<T>`
- `IdempotencyKey`, key digest, request fingerprint, scope, state, and replay result
- `EventEnvelope`, `EventType`

## Database/migration impact

- Migration: none
- Indexes/constraints: none
- Rollback/forward strategy: source-only types; compatible extensions are additive, contract changes require a Change Request

## Runtime/deployment impact

- New bindings/env/secrets: none
- Worker compatibility: compiles for host and `wasm32-unknown-unknown`
- Client-version assumptions: frozen P01 JSON field names

## Tests added

- Unit tests for ID validation, timestamp validation, error/error-code wire shapes, cursor opacity, idempotency scope, event shape, and redacted Debug output
- `cargo test --workspace`: 47 Rust tests passed at P01 integration gate
- `cargo clippy --workspace --all-targets -- -D warnings`: passed
- `cargo check --workspace --target wasm32-unknown-unknown`: passed

## Known limitations

- Trusted runtime boundaries generate random IDs and timestamps; pure core code does not depend on Worker globals.
- Product principal/org authorization semantics belong to later feature packets.

## Downstream agent notes

P02 can build identity and authorization modules against `ActorId`, `OrganizationId`, and `RequestContext` without importing the Worker environment.

## Do not assume

- An opaque ID is evidence of authorization.
- P01's anonymous actor placeholder is an authenticated principal.
