# P04-MOD-02 handoff — Credential domain

- Contract: `p04-cg-v1`.
- Implemented typed ownership/mode/status, precedence and resolution checks in `apps/api/src/modules/credentials.rs`; organization API supports organization, user, and user-bound service-account metadata, while platform credentials remain operator-provisioned.
- Added AES-GCM Web Crypto adapter, ciphertext/nonce/key-version persistence, fingerprint masking, rotation lineage, revoke, last-used tracking, and tenant-scoped reads in `apps/api/src/adapters/crypto.rs` and `apps/api/src/repositories/ai.rs`.
- Plaintext is accepted only at create/rotate and decrypted immediately before the trusted provider dispatch boundary; responses/events/logs contain metadata only.
- Evidence: crypto/credential unit tests, P04 smoke secret-redaction assertions, revoked-credential route test, and production build dry-run.
