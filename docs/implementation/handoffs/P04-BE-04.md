# P04-BE-04 handoff — Streaming inference gateway

- Contract: `p04-cg-v1`.
- Implemented native and OpenAI-compatible inference endpoints in `apps/api/src/routes/inference.rs` with stable request IDs, alias routing, policy/credential checks, meaningful-output preflight before commitment, fetch and per-read deadline/cancellation propagation, SSE decoding, backpressure-preserving `Body::from_stream`, native/chat envelopes, and usage/budget reservation finalization. A stream drop/abort guard schedules cancellation finalization when the Worker delivers a disconnect.
- Persists dispatched/no-output/committed/final states, usage without content, budget decisions/reservations, health, TTFT/total latency, and `usage.recorded.v1` events.
- Evidence: 131 Rust tests, WASM check/build, production dry-run, and P04 smoke covering streaming, non-stream JSON/error rejection, metadata-only preflight, fallback, post-output failure, timeout, revoked credential, stale version, local-only credential, SSRF, capability mismatch, idempotency, and cross-tenant denial. The local runtime accepted a downstream abort after the first chunk but did not emit a cancellation D1 row; the signal/drop finalizer is therefore code-verified, while platform disconnect delivery remains an explicit integration follow-up.
