# Work Packet Handoff — P05-BE-04

## What changed

Implemented the F16 audit read surface and P05 event-consumer support without creating a second audit authority. Device-initiated decisions write `security_events` in the same D1 batch as the business mutation; the queue-side P05 handler validates/redacts events and can optionally project an idempotent audit row for callers that explicitly enable it.

## Coverage

- Tenant-first, keyset-paginated audit queries with run/session/device/action/outcome filters.
- P05 run/agent-session/tool-call correlation columns with bounded metadata fallback.
- Recursive allow-listed metadata redaction, immutable append behavior, and safe debug output.
- Stable cross-tenant, malformed, oversized, and unsupported-event failures.
