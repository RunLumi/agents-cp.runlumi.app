# P04-BE-02 handoff — Secret storage adapter

- Contract: `p04-cg-v1`.
- `apps/api/src/adapters/crypto.rs` uses Worker Web Crypto AES-GCM, validates a 32-byte hex key, generates a fresh nonce, and redacts envelope debug output.
- Production requires `CREDENTIAL_ENCRYPTION_KEY`; only the explicit development environment uses the deterministic fixture key.
- Credential repositories store ciphertext, nonce, key version, fingerprint, ownership, and lifecycle metadata; no reveal endpoint exists.
- Evidence: crypto tests, P04 smoke response/log redaction checks, local-only registration, encrypted-row/plaintext-column D1 audit, and Worker production dry-run.
