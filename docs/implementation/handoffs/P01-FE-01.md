# Work Packet Handoff — P01-FE-01

## What changed

Added a small typed API client with schema validation and stable error-code handling, accessible async error states with request IDs/retry, a React render error boundary, and a development-only integration panel that displays D1/outbox status. The shell uses the supplied Lumi logo and light design tokens.

## Contracts consumed

- Contract Gate commit: `7835fd9` (`p01-cg-v1`)
- APIs: `/api/health`, `/api/v1/meta`, development-only foundation check, `ApiError`
- Permissions: UI availability never establishes permission
- Events: development status is keyed by opaque `event_id`
- Schema/policy versions: none

## Contracts produced

- Typed `getHealth`, `getApiMeta`, `createFoundationCheck`, and status client methods
- `ApiClientError` normalization and safe presentation helpers
- Root `AppErrorBoundary` with a keyboard-accessible reload action
- Development probe with stable idempotency key across safe retries

## Database/migration impact

- Migration: none
- Indexes/constraints: none
- Rollback/forward strategy: client-only; server contract is versioned and additive

## Runtime/deployment impact

- New bindings/env/secrets: none
- Worker compatibility: development UI uses `/api` proxy; panel is removed by production Vite build
- Client-version assumptions: JSON shape validators reject unexpected responses instead of blindly casting

## Tests added

- API client tests for health success, stable API errors/request IDs, message redaction, malformed JSON, network and abort failures, and the frozen empty POST body/header
- Final web verification: 10 Vitest tests, TypeScript, Oxlint, Oxfmt, production Vite build, Rust tests, Clippy, WASM target check, and Worker dry run all passed. Direct component commands were used because the host pnpm wrapper recursively attempted to install the pinned pnpm version.
- Browser review: API connected, create returned `pending`, refresh displayed D1-backed `delivered`; retry recovered after a deliberate local Worker outage.
- Production bundle: JS 72.69 KiB gzip, CSS 4.47 KiB gzip.

## Known limitations

- Authentication, organization selection, and feature screens belong to later phases.
- Real fonts are not vendored in this repository; the interface uses the configured Geist/Noto/system fallback stack.

## Downstream agent notes

Use `requestJson` and stable error codes for feature clients. Keep retry enabled only for safe reads or mutations with an idempotency key.

## Do not assume

- An HTTP success JSON body has the expected type without validation.
- All errors are retryable.
- The internal panel is present in production.
