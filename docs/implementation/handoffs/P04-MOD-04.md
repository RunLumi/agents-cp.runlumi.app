# P04-MOD-04 handoff — Retry/fallback state machine

- Contract: `p04-cg-v1` lifecycle `not_dispatched → dispatched_no_output → stream_committed → completed | failed`.
- Implemented bounded `RetryController`, pre-output candidate fallback, provider health transitions, persisted lifecycle updates, and terminal failure finalization in `apps/api/src/modules/inference.rs` and `apps/api/src/routes/inference.rs`.
- The first non-empty provider chunk commits the stream; no later candidate is selected. Provider error SSE events are normalized to terminal errors.
- Evidence: unit tests for retry/fallback, fixed/weighted selection, timeout/deadline, and decoder boundaries; P04 smoke covers bounded backoff, pre-stream fallback, side-effect-safe tool requests, and post-output no-fallback; D1 query shows completed/failed states and fallback counts.
