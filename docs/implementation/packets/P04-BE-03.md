## Outcome
Provide vendor-neutral adapters for OpenAI-compatible, Anthropic-style, and development mock providers with request translation, stream decoding, error normalization, usage extraction, and endpoint validation.

## In scope
- Adapter request/event contracts and pure translation.
- Worker fetch transport for approved server-controlled endpoints.
- SSRF/redirect/header allowlist protections.

## Explicitly out of scope
- Route persistence and client-facing route selection.
- Exposing provider SDK types.

## Write surface


- Cargo manifest if a minimal stream dependency is required

- events: inference.completed/failed.
- policy schema: allowed providers/models.
- generated types: none.

- [x] Errors normalize without raw body leakage.
