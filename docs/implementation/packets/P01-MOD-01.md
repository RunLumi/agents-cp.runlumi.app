## Outcome

Provide pure, Worker-compatible value types and domain interfaces for request context, IDs, errors, pagination, idempotency, and versioned events so adapters and handlers share one contract.

## In scope

- `apps/api/src/core/**`: opaque ID/value types, request context and actor placeholders, UTC timestamp representation, error taxonomy, cursor page types, idempotency command/result types, event envelope.
- Unit tests for validation, serialization, cursor errors, and contract shape.

## Explicitly out of scope

- Organization-specific domain rules, authentication, permission decisions, or product resources.
- Cloudflare bindings, D1 SQL, HTTP middleware, or frontend code.
- New runtime dependencies without a coordinator-approved compatibility and size note.

## Write surface

Allowed paths:

```text
apps/api/src/core/**
```

Shared files requiring coordinator approval:

- `apps/api/src/lib.rs`, `apps/api/src/app.rs`, and `apps/api/Cargo.toml` are coordinator-owned.

## Frozen contracts consumed

- API: P01-CG error/status map and `/api/v1` convention.
- Entities: `RequestContext`, optional `ActorContext`, opaque ID wrappers, `Page<T>`.
- Events: versioned `EventEnvelope` with request/correlation IDs and optional actor/org context.
- Time: RFC 3339 UTC.
- Idempotency: principal/org/endpoint scope, fingerprint, expiry, replay semantics.

## Implementation notes

- Keep core modules independent of `worker::Env`, Axum, and D1.
- IDs are not authorization evidence. Do not add cross-tenant behavior.
- No raw secrets or request bodies in `Debug` implementations or logs.
- Record the exact dependencies/features needed in a note; coordinator controls Cargo manifests.

## Acceptance criteria

- [ ] P01-CG ID/time/context/event/page/error shapes are represented by typed Rust contracts.
- [ ] Invalid opaque IDs/cursors fail as typed errors; page cursor remains opaque.
- [ ] Core tests prove stable serialized field names and no sensitive payload fields.
- [ ] Core code compiles for host and `wasm32-unknown-unknown` after integration.
