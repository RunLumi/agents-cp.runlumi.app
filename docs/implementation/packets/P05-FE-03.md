## Outcome

Provide current spend/usage, budget progress, hard/soft state, denied requests, scope breakdowns, and a lightweight trend view without shipping a heavy chart dependency.

## In scope

- API decoders for usage, cost, budget, reservation, rate-limit, and denial records.
- Usage summary/breakdown/budget progress/denials panels.
- Lazy, accessible basic trend visualization using existing UI primitives.
- Loading, empty, error, permission, and stale-data states.

## Explicitly out of scope

- Billing/invoices, pricing administration, CSV export implementation, and high-volume analytics.

## Frozen contracts consumed

- API/entities: P05-CG usage, CostRecord, Budget, reservation, rate-limit, denial.
- Permissions: `usage.read`, `budgets.read`.
- Events: `usage.*`, `budget.*`, `rate_limit.denied.v1`.
- Policy schema: server-calculated budget state.

## Implementation notes

Use integer minor units and explicit currency/pricing version. Show the reconciliation timestamp and stale indicator; do not recalculate historical cost in the browser. Keep trend rendering lightweight and lazy.
