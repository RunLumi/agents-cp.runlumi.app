## Outcome
Add a provider-adapter boundary, subscription/grace state, effective Lumi entitlement projection, expiring audited overrides, and short-lived signed device license snapshots.

## In scope
- Plan/subscription/entitlement/grant/license D1 repositories.
- Billing/entitlement browser reads and internal license/override adapter; provider portal/change/cancel operations are adapter-backed and never collect card data. The existing `/devices/policy` response is the only device license authority.
- Provider callback adapter boundary with stable mapping.
- Audit/outbox events and downgrade over-limit projections.

## Explicitly out of scope
- Product logic keyed by provider product/price IDs.
- A public browser entitlement-override route.
- Export/deletion or automation scheduler behavior.
