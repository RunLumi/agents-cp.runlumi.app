## Outcome
Represent provider credential ownership, lifecycle, version lineage, fingerprinting, policy precedence, and safe resolution handles without exposing plaintext.

## In scope
- Credential ownership modes and policy precedence.
- Rotation/revocation state rules and masking helpers.
- Tests for cross-user/org handles, local-only metadata, and no Debug leakage.

## Explicitly out of scope

## Implementation notes
A logical credential handle is resolved only after central authorization and immediately before outbound use. Local-only credentials never contain ciphertext.

## Acceptance criteria
- [x] Raw secret is not part of metadata or Debug output.
- [x] Revoked credentials are excluded from new routing.
- [x] Rotation preserves lineage and can revoke the prior version.
- [x] User credentials cannot be selected by another user or organization.
