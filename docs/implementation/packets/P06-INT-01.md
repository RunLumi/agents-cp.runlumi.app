## Outcome
Deliver a LumiAgents/ZCode leased automation seam that validates occurrence identity and current policy, executes one logical occurrence once, returns the P05 run ID/result, and handles reconnect without burst duplicate replay.

## In scope
- External LumiAgents/ZCode automation/lease protocol types and runtime seam.
- Occurrence ID, lease token fingerprint/claim/fence, policy/license freshness, and result mapping.
- Normal versus off-peak safety behavior and reconnect/catch-up handling.
- Reuse the existing cron/interval engine, off-peak continuation/ticket-expiry semantics, managed inference context, and V4 transport recovery seams behind adapters.
- Do not reuse local `AutomationRepo.claimDue`/`recoverInterrupted`, the local 5-minute misfire grace, in-memory dispatch context, or colon-delimited local run IDs as P06 authority; these cannot represent server leases, fences, or `ambiguous`.

## Explicitly out of scope
- Worker schedule authority, billing provider implementation, or public CUA implementation.
- Duplicating the control-plane state machine in the client.
