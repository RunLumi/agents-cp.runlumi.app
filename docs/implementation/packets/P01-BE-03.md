## Outcome

Ensure every HTTP request receives a request context and stable response header, and every error path returns the frozen JSON envelope with bounded, secret-safe telemetry.

## In scope

- `apps/api/src/http/**` and non-router route response/error helpers under `apps/api/src/routes/**`.
- Request ID/correlation context, body-size/media-type guards, stable error conversion, 404/405 normalization, safe structured logs, timing.
- Anonymous/test principal hook only; no authentication or authorization implementation.

## Explicitly out of scope

- Central route registration, D1 business endpoints, auth, tenant permission logic, provider timeouts, or product-specific responses.
- Worker entrypoint, dependencies, Wrangler config, or frontend client.

## Write surface

Allowed paths:

```text
apps/api/src/http/**
apps/api/src/routes/errors.rs
```

Shared files requiring coordinator approval:

- `apps/api/src/lib.rs` and `apps/api/src/app.rs` are coordinator-owned.

## Frozen contracts consumed

- `RequestContext`, `ApiError`, status/code map, `X-Request-ID`, and 1 MiB JSON limit in P01-CG.
- No client-supplied IDs establish principal, organization, or resource scope.
- Error `details` is an object; internal causes are redacted.

## Implementation notes

- The Worker generates a fresh request ID at its HTTP boundary; do not trust an inbound request ID as the request's identity.
- A validated correlation ID is diagnostic only and defaults to the request ID.
- Normalize Axum extractor, body-limit, and unknown-route errors through the same envelope.
- Keep logs structured and bounded; do not log request/response bodies, headers, credentials, or event payloads.
- Middleware should be small and have no new heavy tower dependency.

## Acceptance criteria

- [x] Success, extractor error, route miss, method mismatch, and internal failure carry the same generated ID in header/envelope.
- [x] Malformed/oversized/non-JSON requests fail with stable codes and no body leakage.
- [x] Structured logs contain request/correlation ID, route/status/timing only; explicit tests assert secret and body absence.
- [x] Timing and error paths have deterministic HTTP tests.
