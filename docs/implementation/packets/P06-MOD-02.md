## Outcome
Implement a typed evaluator for Lumi entitlement keys, subscription/grace state, limits, and expiring overrides while keeping authorization, budgets, and provider account state independent.

## In scope
- Entitlement key/value validation and effective-value projection.
- Plan/subscription/grace/past-due state evaluation.
- Downgrade over-limit calculations without data deletion.
- Expiring override validation and stable denial reasons.
- Provider-entitlement separation interfaces.

## Explicitly out of scope
- Payment-provider HTTP calls, D1 repositories, or UI.
- Treating provider product/price IDs as product entitlements.

## Write surface
```text
apps/api/src/modules/entitlements/**
```
Shared files requiring coordinator approval: none.

## Frozen contracts consumed
- API: P06 entitlement and license snapshot schemas.
- entities: `Plan`, `Subscription`, `EntitlementDefinition`, `EntitlementGrant`, `LicenseSnapshot`.
- policy schema: P06 entitlements section.
- errors: P06 entitlement/license reasons.

## Acceptance criteria
- [ ] Product code evaluates only stable Lumi keys.
- [ ] Grace expiration is deterministic and separately bounded from cloud-paid inference.
- [ ] Downgrade blocks new/expansion limits without deleting history.
- [ ] Overrides require expiry/reason and cannot become permanent silently.
- [ ] Provider account state cannot change Lumi subscription state by accident.
