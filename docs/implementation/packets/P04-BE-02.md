## Outcome
Encrypt credential material with Worker Web Crypto, persist ciphertext/nonce/key-version metadata only, and resolve plaintext only at the outbound adapter boundary.

## In scope
- AES-GCM key adapter and redaction-safe errors.
- Credential create/list/rotate/revoke persistence.
- Development-only deterministic key fallback; production fails closed without a secret.

## Explicitly out of scope
- Provider-specific outbound request construction.
- Returning or revealing plaintext.
