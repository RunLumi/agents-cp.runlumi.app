## Outcome

Provide dense, accessible run/session list and detail views with state, model/provider metadata, tool/approval summary, usage, failure reason, artifacts, and safe cancel/retry actions.

## In scope

- API client decoders/types for P05 agent/session/run/event/artifact routes.
- Runs list/detail/timeline feature components and loading/empty/error/permission states.
- Keyboard-reachable cancel/retry controls with consequence copy and idempotency keys.
- Organization dashboard/navigation integration using existing P04 panel patterns.

## Explicitly out of scope

- Tool policy editor, budget charts, direct desktop execution, and raw prompt/response display.

## Frozen contracts consumed

- API/entities: P05-CG AgentDefinition, Session, Run, RunEvent, ArtifactRef.
- Permissions: `sessions.*`, `runs.*`.
- Events: state/cancel/retry/artifact event types.
- Policy schema: current server state only; UI never computes authorization.

## Implementation notes

Use stable error codes, preserve org/project context on every request, and render metadata-only payloads. Preserve visible focus, semantic headings, and narrow-layout overflow intentionally. Do not put raw event payloads into browser storage.

## Acceptance criteria

- [ ] List/detail/timeline render all required async states.
- [ ] Terminal run history is visibly append-only and retry is a new attempt.
- [ ] Cancel/retry are keyboard reachable, confirmed where destructive, and idempotent.
- [ ] Cross-scope/permission errors do not leak resource details.
- [ ] No raw prompt, tool argument, token, or secret is persisted in UI state/storage.
- [ ] Desktop and narrow layouts follow DESIGN.md and relevant screen references.
