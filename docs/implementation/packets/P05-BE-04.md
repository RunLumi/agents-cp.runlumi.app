## Outcome

Ensure run, approval, privileged tool, budget, usage, and artifact actions produce correlated immutable audit/operational events with bounded, redacted metadata and observable failures.

## In scope

- P05 audit/outbox event registration and consumers.
- Correlation/request/run/session/device propagation across routes and background jobs.
- Redaction helpers and structured metadata conventions for tool/budget events.
- Queue failure/dead-letter visibility and idempotent event handling.

## Explicitly out of scope

- Product audit UI, provider billing, and retention implementation owned by later phases.

## Frozen contracts consumed

- API: P05-CG event/audit schemas.
- Entities/events: all P05 event names and RunEvent sequence.
- Permissions: `audit.read`; writes occur only after domain authorization.
- Policy schema: no prompt/response/secret fields.

## Implementation notes

Use the existing P01/P02 audit and outbox conventions. High-cardinality IDs belong in event payloads/traces, not metric labels. Failed outbox deliveries must be visible and replayable without duplicating domain mutations.
