## Outcome

Apply current organization/project browser and computer-use policy in the desktop execution host before each sensitive action, without moving actual desktop execution to the Worker.

## In scope

- Browser domain, download/upload, authenticated browsing, clipboard, and external submit decisions.
- Computer accessibility, screen capture, keyboard/mouse, shell escalation, and application allow/deny decisions.
- Per-use approval handshake for high-impact actions.
- Policy version/expiry cache with fail-closed refresh behavior.

## Explicitly out of scope

- Browser automation implementation, screen-control implementation, and policy UI beyond P05-FE-02.

## Implementation notes

Cache only versioned, non-sensitive policy metadata. Re-evaluate current policy at each sensitive action or after expiry; a cached allow is not valid across a policy version change. A prompt cannot enable a denied capability.
