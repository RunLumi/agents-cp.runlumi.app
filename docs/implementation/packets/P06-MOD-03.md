## Outcome
Implement the data-class registry, retention/logging-mode planner, export scope planner, and resumable deletion plan with legal/security retention rules.

## In scope
- Data classification and governance metadata validation.
- Per-class export/deletion/tombstone behavior.
- Bounded deletion step planning and retry/resume decisions.
- R2/reference traversal rules and backup lifecycle notes.
- Stable legal-hold and over-limit reasons.

## Explicitly out of scope
- D1 queries, R2 bindings, queue consumers, or browser UI.
- Deleting rows directly from domain handlers.

## Write surface
```text
apps/api/src/modules/data_governance/**
```

## Frozen contracts consumed
- entities: `DataGovernancePolicy`, `ExportJob`, `DeletionJob`.
- policy schema: P06 data-governance section.
- errors: P06 export/deletion reasons.
- events: export/deletion event names.

## Acceptance criteria
- [ ] Every persistent P06 class has sensitivity, scope, retention, export, deletion, and logging metadata.
- [ ] Metadata-only is the default.
- [ ] Deletion plans are bounded, idempotent, and resumable.
- [ ] Legal/security retention is minimized and tombstoned.
- [ ] Export content is never treated as a public D1 blob.
