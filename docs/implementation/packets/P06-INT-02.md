## Outcome
Deliver a short-lived signed license/entitlement snapshot to managed LumiAgents/desktop clients, preserve bounded offline grace, and ensure transient billing outages do not brick unrelated local work.

## In scope
- External LumiAgents license snapshot types, verification, and policy freshness seam.
- P03 policy/device snapshot extension points and P06 license block in the existing policy response.
- Signed snapshot audience, anti-rollback, key rotation, and separate policy-fresh/offline-valid expiries.
- Grace/override behavior and cloud-paid versus local-only capability distinction.

## Explicitly out of scope
- Payment provider API calls in the client.
- Permanent client-side entitlement flags or provider product/price IDs.
