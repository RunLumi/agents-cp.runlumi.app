## Outcome
Provide tenant-isolated asynchronous export and resumable deletion jobs with R2 artifact metadata, short-lived access, audit, retention, and idempotent state transitions.

## In scope
- Data policy, export job, deletion job, and deletion task persistence.
- Queue-backed export/deletion workers and retry/resume handling.
- R2 adapter boundary for encrypted short-lived export artifacts.
- Re-authorized download grants, legal-hold checks, and audit/outbox events.

## Explicitly out of scope
- Direct destructive D1 deletes from HTTP handlers.
- Exposing permanent public URLs or exporting another tenant's data.

## Acceptance criteria
- [ ] Export is asynchronous, tenant-scoped, encrypted/access-controlled, and short-lived.
- [ ] Deletion can resume after partial failure without duplicate side effects.
- [ ] Object/blob/cache/index copies are traversed before completion.
- [ ] Legal/security retention is explicit and minimized.
- [ ] Every state change is auditable and idempotent.
