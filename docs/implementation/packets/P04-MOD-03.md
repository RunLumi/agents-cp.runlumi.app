## Outcome
Compile immutable route versions and select candidates deterministically by capability, policy, lifecycle, health, weights, and ordered fallback.

## In scope
- Route/version value types and config validation.
- Fixed, ordered fallback, and weighted-health-aware selection.
- Cooldown filtering and deterministic test injection.

## Explicitly out of scope
- Network dispatch, D1 persistence, and streaming response conversion.

## Write surface
Allowed paths:
```text
apps/api/src/modules/routing.rs
```

## Frozen contracts consumed
- API: route create/publish/rollback and inference route lookup.
- entities: Route, RouteVersion, RouteCandidate.
- permissions: routes.read, routes.manage, inference.use.
- events: route.published/rolled_back.
- policy schema: allowed aliases/models/providers.
- generated types: none.

## Implementation notes
Selection is pure and receives health/credential availability as inputs. It never reads a client role or a raw credential.

## Acceptance criteria
- [x] Published route versions cannot be mutated.
- [x] Capability/policy/lifecycle filters run before selection.
- [x] Deterministic weighted selection can be tested with an injected value.
- [x] Provider cooldown excludes only the affected provider scope and expires.
