## Outcome
Provide tenant-scoped automation CRUD/pause/resume/run-now APIs, due occurrence generation, atomic device lease claim, result settlement, and retry/missed-schedule behavior.

## In scope
- `0011_p06_durable_operations.sql` automation tables and indexes.
- Automation repository and D1 atomic occurrence/lease transitions.
- Browser APIs and device due/claim/complete APIs.
- Central authorization, CSRF, idempotency, audit, and outbox integration.
- Queue dispatcher/claim retry integration using P01 outbox primitives.

## Explicitly out of scope
- ZCode/LumiAgents local execution implementation.
- Webhook, billing, or export/deletion endpoints.
