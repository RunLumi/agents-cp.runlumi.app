## Outcome
Make response commitment and safe fallback explicit and heavily unit tested, including timeout, retry, content-after-dispatch, and disconnect cases.

## In scope
- `not_dispatched`, `dispatched_no_output`, `stream_committed`, `completed`, `failed` states.
- Safe retry classification, bounded backoff inputs, and fallback decisions.

## Explicitly out of scope
- Actual provider fetch and database writes.

## Frozen contracts consumed
- API: native/SSE and OpenAI-compatible inference endpoints.

- permissions: inference.use.
- events: inference.requested/completed/failed.
- policy schema: route version and credential mode.
- generated types: none.

## Implementation notes
A conservative first non-empty upstream chunk commits the stream. No fallback is attempted after that point.

## Acceptance criteria
- [x] Pre-output connection/timeout/rate-limit failures can fall back.
- [x] Content followed by failure never falls back.
- [x] Side-effectful/tool-bearing requests are not blindly retried.
- [x] State transitions are deterministic and bounded.
